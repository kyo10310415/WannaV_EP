# ツールの料金概算と円換算

管理者の「API使用量」に概算USD、概算JPY、見積もり方式を表示します。実際の請求額ではありません。OpenAIの料金確認は[公式料金表](https://developers.openai.com/api/docs/pricing)と[利用モデルのページ](https://developers.openai.com/api/docs/models/gpt-5.4-mini)を使い、Standard欄を確認してください。Batch/Flexなど他の料金と混同しないでください。

## Renderに設定する値

文章モデル `OPENAI_OBS_MODEL=gpt-5.4-mini`、画像モデル `OPENAI_KANAU_IMAGE_MODEL=gpt-image-2` の場合。2026-11-10に公式資料を確認しています。

| 環境変数 | 設定例 | 単位・意味 |
|---|---|---|
| `TOOLS_INPUT_USD_PER_MILLION` | `0.75` | 非キャッシュ入力100万tokenのUSD |
| `TOOLS_CACHED_USD_PER_MILLION` | `0.075` | キャッシュ入力100万tokenのUSD |
| `TOOLS_OUTPUT_USD_PER_MILLION` | `4.5` | 出力100万tokenのUSD |
| `TOOLS_SEARCH_USD_PER_CALL` | `0.01` | Web検索1回のUSD（$10/1000回を1000で割る） |
| `TOOLS_CODE_INTERPRETER_USD_PER_CONTAINER` | `0.03` | 新規1GBコンテナ1セッションのUSD |
| `TOOLS_IMAGE_USD_PER_CALL` | `0.10` | **仮の平均見積もり**。画像モデルの入力・出力分を含む1呼び出しのUSD |
| `TOOLS_USD_TO_JPY` | `150` | **換算例**。1 USDを何円として表示するか（自動取得なし） |

Renderの対象Webサービス → Environmentで追加・保存し、設定を反映してください。通貨記号・カンマを付けない数値で入力します。レートは0より大きい値、単価は0以上。空欄や不正値は未設定扱いです。無料でないものに0を設定すると過小評価になります。モデルを変更する場合は文章・画像単価も再確認してください。単価は全ツールで共有します。

## 画像生成の見積もり

かなうさんとYouTube分析官の画像作成モードでは、通常の文章モデルtoken料金に加え、APIが返した画像生成呼び出し数 × `TOOLS_IMAGE_USD_PER_CALL` を加算します。画像を保存できた枚数ではなく、APIの呼び出し数です。確認質問だけで画像を呼ばなかった場合は画像分を加算しません。

**`0.10`はOpenAIの公式固定料金ではありません。** GPT Image 2はtoken課金で、画像サイズ・品質・参照画像・過去の画像を使った編集などで料金が変わります。[公式画像生成ガイドの計算機](https://developers.openai.com/api/docs/guides/image-generation#calculating-costs)で `gpt-image-2`・medium・実際の解像度を指定し、画像出力費用を確認できます。計算機には入力費用が含まれません。画像モデルの入力テキスト（$2.50/100万token）・入力画像（$4/100万token）・出力画像（$15/100万token）の費用を加味し、OpenAIのUsageで実測した画像モデル費用÷呼び出し数を目安に平均額を調整してください。文章モデル費用は別計算なので、この平均額に重ねて含めないでください。複数サイズの共通平均なので、個々の実請求とは差が出ます。

## CSV計算・失敗時・過去データ

ゲーム配信戦略分析官は、CSV点検・公開情報調査・戦略提案で返されたtokenと検索回数を合算し、新規作成した1GBコンテナの料金を1回加算します。Pythonを何度呼んでも同じコンテナを二重加算しません。入力案内だけの `local-intake` は0円です。

新しい利用記録には、見積もりの内訳・適用単価・画像平均方式を保存します。単価が欠けた場合や一部の使用量が取れなかった場合は「一部未算出」とし、判明した費用のみ表示します。APIへの接続失敗などで使用量が分からない場合、実際には追加の課金が発生している可能性があります。unknown/pendingを無料として扱いません。

過去の未算出記録は画像回数だけでは当時の費用を復元できないため、自動で埋めません。旧記録のUSD概算は保持します。JPYは現在設定されているレートを表示時に全期間へ適用する参考値です。税金・決済手数料・カード会社のレート・他アプリの使用分は含みません。請求確認はOpenAIのUsage/Billingを使用してください。
