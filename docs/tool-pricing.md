# ツールの料金概算と円換算

管理者の「API使用量」に概算USD、概算JPY、見積もり方式を表示します。実際の請求額ではありません。OpenAIの料金確認は[公式料金表](https://developers.openai.com/api/docs/pricing)と[利用モデルのページ](https://developers.openai.com/api/docs/models/gpt-5.4-mini)を使い、Standard欄を確認してください。Batch/Flexなど他の料金と混同しないでください。

## Renderに設定する値

文章モデル `OPENAI_OBS_MODEL=gpt-5.4-mini`、画像モデル `OPENAI_KANAU_IMAGE_MODEL=gpt-image-2` の場合。2026-11-10に公式資料を確認しています。

| 環境変数 | 設定例 | 単位・意味 |
|---|---|---|
| `TOOLS_INPUT_USD_PER_MILLION` | `0.75` | 非キャッシュ入力100万tokenのUSD |
| `TOOLS_CACHED_USD_PER_MILLION` | `0.075` | キャッシュ入力100万tokenのUSD |
| `TOOLS_OUTPUT_USD_PER_MILLION` | `4.5` | 出力100万tokenのUSD |
| `TOOLS_SEARCH_USD_PER_CALL` | `0.01` | Web検索1回のUSD（$10/1000回を1000で割る） |
| `TOOLS_CODE_INTERPRETER_USD_PER_CONTAINER` | `0.03` | 新規1GBコンテナ1セッションのUSD |
| `TOOLS_IMAGE_USD_PER_CALL` | `0.10` | **仮の平均見積もり**。画像モデルの入力・出力分を含む1呼び出しのUSD |
| `TOOLS_USD_TO_JPY` | `150` | **換算例**。1 USDを何円として表示するか（手動モードの場合。通常は下記の自動取得を利用） |

Renderの対象Webサービス → Environmentで追加・保存し、設定を反映してください。通貨記号・カンマを付けない数値で入力します。レートは0より大きい値、単価は0以上。空欄や不正値は未設定扱いです。無料でないものに0を設定すると過小評価になります。モデルを変更する場合は文章・画像単価も再確認してください。単価は全ツールで共有します。

## 画像生成の見積もり

かなうさんとYouTube分析官の画像作成モードでは、通常の文章モデルtoken料金に加え、APIが返した画像生成呼び出し数 × `TOOLS_IMAGE_USD_PER_CALL` を加算します。画像を保存できた枚数ではなく、APIの呼び出し数です。確認質問だけで画像を呼ばなかった場合は画像分を加算しません。

**`0.10`はOpenAIの公式固定料金ではありません。** GPT Image 2はtoken課金で、画像サイズ・品質・参照画像・過去の画像を使った編集などで料金が変わります。[公式画像生成ガイドの計算機](https://developers.openai.com/api/docs/guides/image-generation#calculating-costs)で `gpt-image-2`・medium・実際の解像度を指定し、画像出力費用を確認できます。計算機には入力費用が含まれません。画像モデルの入力テキスト（$2.50/100万token）・入力画像（$4/100万token）・出力画像（$15/100万token）の費用を加味し、OpenAIのUsageで実測した画像モデル費用÷呼び出し数を目安に平均額を調整してください。文章モデル費用は別計算なので、この平均額に重ねて含めないでください。複数サイズの共通平均なので、個々の実請求とは差が出ます。

## CSV計算・失敗時・過去データ

ゲーム配信戦略分析官は、CSV点検・公開情報調査・戦略提案で返されたtokenと検索回数を合算し、新規作成した1GBコンテナの料金を1回加算します。同じ相談の有効なコンテナを再利用した回は作成料金を加算しません。Pythonを何度呼んでも同じコンテナを二重加算しません。入力案内だけの `local-intake` は0円です。

新しい利用記録には、見積もりの内訳・適用単価・画像平均方式を保存します。単価が欠けた場合や一部の使用量が取れなかった場合は「一部未算出」とし、判明した費用のみ表示します。APIへの接続失敗などで使用量が分からない場合、実際には追加の課金が発生している可能性があります。unknown/pendingを無料として扱いません。

過去の未算出記録は画像回数だけでは当時の費用を復元できないため、自動で埋めません。旧記録のUSD概算は保持します。JPYは利用開始日の保存済み為替による参考値です（下記の日次自動取得を参照）。税金・決済手数料・カード会社のレート・他アプリの使用分は含みません。請求確認はOpenAIのUsage/Billingを使用してください。

## 日次自動為替と全ツール共通の上限（2026-11-11追加）

- `TOOLS_FX_AUTO_ENABLED=true`（未設定時も有効）：Frankfurterの公開APIからUSD/JPY参考レートを取得。APIキー・有料契約は不要。[提供元の仕様](https://frankfurter.dev/)
- `TOOLS_DAILY_BUDGET_JPY=100`（未設定時も100円）：全権限・全ユーザー・全6ツール合計の日本時間1日上限。`off`で明示的に無効化、`0`は全送信停止。不正値では利用を許可しません。

起動時と毎日00:05（Asia/Tokyo）に取得し、日付分が未取得なら送信開始時にも取得します。日次テーブルに適用日・レート・提供元・公表日を保存し、その日について最初に保存された値を固定します。休日は提供元の直近公表値です。API障害時は7日以内の保存済み公表値を持ち越し、`carry_forward`と公表日を管理画面へ表示します。過去値もない/古すぎる場合は新規送信を停止し、履歴閲覧は維持します。日次取得は参考レートでありカード会社の決済レートではありません。

各利用行には送信開始時の日本時間の日付・為替・概算JPYを保存します。処理完了が翌日でも開始日に計上します。後日の為替や環境変数変更では保存済み金額を変更しません。変更前の記録は、その日に保存された為替がある場合だけ表示時に換算し、それもなければJPYは未算出です。現在レートで過去全期間を換算し直しません。自動取得時の`TOOLS_USD_TO_JPY`は不要です。`TOOLS_FX_AUTO_ENABLED=false`の場合のみ、従来の手動レートを利用開始時に保存できます。

### 上限の判定と同時送信

送信受付の既存DBトランザクション/アドバイザリロック内で上限を判定し、残りの枠を処理中の確保額として保存します。概算が判明したら実際の概算金額で置き換えます。低額上限を並行処理で使い越さないため、上限有効時は全ユーザー合計で1処理ずつ受け付けます。処理中は他の送信に待機メッセージを返します。最近追加された切断時の同時実行枠保持は維持します。

金額が100円以上になった後の送信はAPIを呼ばず拒否し、「現在使用できません。明日以降にお試しください。」と表示します。翌日00:00から新しい日付の集計になるため再開できます（開いたまま送信不可の画面は再読み込み）。送信回数の既存日次/月次上限も維持します。会話の閲覧・添付保存は止めません。

API料金は処理後に分かるため、開始済みの1処理を途中で止めたり、その1処理が残額を超えないことを保証したりはできません。また画像は設定平均単価のため、OpenAIの実請求額100円を厳密に保証する制御ではありません。実請求との相違はOpenAIで確認してください。

単価が不足している場合はAPI送信前に停止します。料金不明の呼び出しは確保額を維持し、その日は追加送信を抑止します。移行前の当日の未算出行も無料扱いせず、上限相当額として扱います。この場合は翌日まで停止することがあります。過去の料金・使用履歴は書き換えません。

### 検証時の分離

既存回帰テストは `TOOLS_FX_AUTO_ENABLED=false`、`TOOLS_DAILY_BUDGET_JPY=off` で外部為替APIを呼ばず検証します。専用テストは隔離DBで100円上限・固定レート・取得失敗・日本時間の日付境界・未知料金・API未呼び出しを検証します。本番の通知・同期を起動してテストしないでください。

同じ相談でのコンテナ・計算結果・公開調査の再利用条件は[ゲーム配信戦略分析官のコスト削減](obs-master.md#ゲーム配信戦略分析官のコスト削減2026-11-11)を参照してください。節約額はAPI呼び出し量・期間で変わり、固定の削減率を保証しません。
