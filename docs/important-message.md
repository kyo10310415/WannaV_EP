# 重要メッセージの設定

管理者はダッシュボードの「重要メッセージ管理」から、本文、表示開始・終了日時（日本時間）、任意の関連URLを設定できます。終了日時に達すると表示されなくなります。「表示を停止する」で設定を削除できます。

表示期間中、ログイン後のダッシュボードに重要メッセージが表示されます。利用者が「本日は表示しない」にチェックを入れて閉じると、そのアカウントでは日本時間の当日中、端末を変えても再表示されません。チェックせず閉じた場合は、次にダッシュボードを開いたときに再表示されます。管理者が本文や期間を保存し直した場合は新しい版として扱い、当日非表示の利用者にも再表示されます。

表示状態と当日非表示の記録はPostgreSQLに保存します。既存環境変数の追加は不要です。
