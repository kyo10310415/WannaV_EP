# 引き継ぎ・延長審査の廃止と進捗管理

- 引き継ぎ・延長審査のページ、API、ナビゲーション、自動審査作成ジョブを削除。
- デプロイ後の起動時マイグレーションで `handover_info`、`extension_reviews`、プロフィールの引き継ぎ完了フラグ2列、および専用操作ログを削除する。削除は単一トランザクションで冪等に実行し、CASCADEは使わない。
- データ削除は元に戻せない。復元が必要な場合はデプロイ前のDBバックアップを使用する。旧バージョンのプロセスを並行稼働させず、マイグレーション後に旧アプリへ戻さない。
- 生徒アカウント、Notion情報、生徒プロフィールの開始日・契約情報、学習履歴、支払い情報、満足度回答、他機能の操作ログは保持する。外部Discordに送信済みの通知は削除しない。
- ユーザー進捗管理の一覧と全サマリーは「アクティブ」または「レッスン準備中」、かつ「永久会員以外」の生徒が対象。Notion情報を優先し、未設定項目はプロフィールへfallbackする。契約プラン未設定は永久会員とは判定せず対象に含める。
- 「総生徒数」を「アクティブ生徒数」に変更。「契約アクティブ」カードを削除。
- 生徒の全体進捗率をクリックすると通常コース別の完了数・教材数・進捗率を表示する。全体進捗と同じくスペシャルコンテンツはこの内訳から除外し、従来の学習詳細で確認できる。
